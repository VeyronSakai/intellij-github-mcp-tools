# GitHub MCP Toolset Changelog

## [Unreleased]
### Added
- `github_list_repositories` / `github_select_repository`: list the project's GitHub repositories and select one in the Pull Requests tool window
- `github_open_pull_request_view` / `github_close_pull_request_view`: show a pull request (details, timeline, diff) in the IDE and close it again
- `github_open_pull_request_list`: show (and optionally reload) the pull request list
- `github_close_tool_window`: hide the Pull Requests tool window
- `github_get_pull_request_filter` / `github_set_pull_request_filter`: read and set the filter of the pull request list
